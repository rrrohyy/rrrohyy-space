# rrrohyy-space

Personal portfolio and tools hub for Yunyoung Roh.

Website: https://rrrohyy.github.io/rrrohyy-space/

## Files

- `index.html`: responsive portfolio, project filters and details, and personal tools.
- `.nojekyll`: serves the site as static HTML.

## Tools

The date planner is hosted at https://eclectic-paletas-acfcfc.netlify.app/ . Its source repository has not yet been identified. Meeting shortcuts are stored only in the visitor's browser using localStorage.

## Publishing

GitHub Pages serves the `main` branch from `/ (root)`. Changes to `index.html` are published automatically.
